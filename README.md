# Zona NoVAST — собственные обновления Android TV

**Статус:** инфраструктура сборки. Автоматическая установка с телевизора **пока не подключена**; реклама на устройстве ещё не проверена. Это не официальный продукт Zona.

## Назначение

- Ежедневно проверить официальную Android-сборку Zona (публикуемый Zona URL: `https://zon.im/a`).
- Сверить сертификат издателя с контрольной подписью исходного `zona5.apk`.
- Если вышла новая версия, применить **только заранее проверенный патч VAST**; при изменении метода остановиться с ошибкой.
- Подписать нашей постоянной подписью (v1+v2), проверить ZIP, подписи и дифф и опубликовать APK в Releases.
- Сформировать `updates/latest.json` для будущего механизма обновления на Android TV.

## Ограничения

Автосборка и автопубликация **не равны автообновлению установленной Zona**. Для этого нужно дополнительно изменить клиент Zona и протестировать его на ТВ-боксе. Android может потребовать подтверждение установки. Проверка релиза не гарантирует, что реклама полностью отключена или что новая версия работает: необходим реальный запуск.

Не устанавливайте неподтверждённые сборки на устройство с важными данными. При неуспешной проверке код не должен публиковать APK.

## Настройка секретов (публичный репозиторий)

Файл приватного ключа `signing.p12`, пароль, base64 ключа **никогда не загружать в Git и GitHub Releases**. Для GitHub Actions нужны два **Repository secrets** (Settings → Secrets and variables → Actions):

- `ZONA_SIGNING_P12_B64`: base64 от существующего приватного P12 файла подписи ранее выданного APK;
- `ZONA_KEY_PASSWORD`: пароль именно к этому P12.

Рабочий процесс настроен так, чтобы **без обоих секретов публикация пропускалась**, а проверка официальной версии продолжалась. Используется контроль отпечатка сертификата: неправильный ключ блокирует сборку. Важно защищать доступ на запись в репозиторий и Actions: любой редактор workflow потенциально может раскрыть secrets.

## Исходный код

`zona_build.py` — локальный воспроизводимый патч ровно одного метода в официальном APK. Код пересборки не зависит от сторонних модификаций FreeZona; репозиторий `azazelich/melta` не используется.

Этот проект не связан с авторами Zona. Не включайте чужой APK в репозиторий без разрешения правообладателя.
